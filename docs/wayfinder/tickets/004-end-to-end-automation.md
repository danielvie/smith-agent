- Label: `wayfinder:grilling`

## Question

Should the first POC be read-only, UI-focused with mocked tools, or exercise actual automation?

## Resolution

Exercise one end-to-end trusted-workspace flow with read/write/edit tools, an explicitly approved shell action, one MCP stdio server, one loaded skill, steering/cancellation, shared terminal/browser events, rich Markdown/math/chart rendering, and a Windows compiled artifact.
